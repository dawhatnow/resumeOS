**Status:** not started  
**Job:** `--rewrite` rephrases **approved** bullets locally. Off by default. Never used for JD fetch or match.

No Gemini, OpenAI, or Anthropic. User installs Ollama themselves. If it’s slow, they omit `--rewrite`.

## How to code it

1. Default path: `NullProvider` — approved plan text unchanged.
2. `resume new --rewrite` constructs `OllamaProvider` (model from env, e.g. `RESUME_OLLAMA_MODEL`).
3. Writer sends only the approved bullets + JD keywords, not the whole warehouse.
4. Guard fails → retry once → else original wording. Never write LLM text into `profile.yaml`.

## Done when

`--rewrite` changes wording on a line that still passes the guard; failure leaves the original bullet.
