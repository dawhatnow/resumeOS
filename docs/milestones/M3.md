# M3 — Review + PDF (plan)

**Status:** not started  
**Job:** edit the plan in the terminal, then write a one-page PDF to Desktop. Default wording = original bullets.

## What to build

```
ResumePlan
  → review loop (toggle / edit / reorder / approve)
  → truth check on edits
  → Typst template
  → fit loop (drop lowest bullet if > 1 page)
  → ~/Desktop/<filename>.pdf
```

## New files

| File | Function |
|---|---|
| `app/review.py` | terminal review; no chat |
| `app/render.py` | fill Typst + compile + fit |
| `app/guard.py` | edit still maps to a real warehouse bullet; numbers must already exist |
| `templates/resume.typ` | single-column one-pager |

## Libraries

| Lib | Use |
|---|---|
| **Rich** | review screen (selected vs dropped, coverage) |
| **questionary** (optional) | checkboxes / select; or Rich + Typer prompts only |
| **Typst** (CLI binary, not a pip package) | layout + PDF. User installs `typst` locally — $0 |
| stdlib `subprocess` | `typst compile` |

No Docx, no paid render API. `--rewrite` is M6; here use original bullet text (`NullProvider` later, or just copy `bullet.text`).

## How to code it

1. Show company/title, `must-haves k/n`, keep-list with reasons, preview as text.
2. Actions: approve, toggle, add from warehouse, edit line, reorder.
3. Edited line: run guard (source `id` exists; any number in the new text already appears on that bullet). Reject and say why.
4. Ask filename (default `Company_Role.pdf`).
5. Write Typst, compile, if page count > 1 drop lowest-scored bullet and compile again.

## Done when

One local run: approve → one-page PDF on Desktop, no paid API.
