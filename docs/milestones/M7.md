## How to publish

1. Account + API token at pypi.org.
2. `python -m build`
3. `twine upload dist/*`
4. Users: `pipx install resumeos` then `resume`

Without PyPI: `pipx install git+https://github.com/you/resumeOS.git`.

Do this after M3 at least (import-only CLI is a weak first release).
