# M5 — Board fetchers (as built)

**Status:** done  
**Job:** `resume new <url>` reads the job straight from Greenhouse, Lever, and Ashby, and from most other career sites, without pasting.

## What handles what

| URL | Fetcher | How |
|---|---|---|
| `boards.greenhouse.io/<board>/jobs/<id>`, `job-boards.greenhouse.io/…` (and `.eu.`) | `GreenhouseFetcher` | public board API `boards-api.greenhouse.io/v1/boards/<board>/jobs/<id>` |
| company site with `?gh_jid=<id>` (e.g. `stripe.com/jobs/search?gh_jid=…`) | `GreenhouseFetcher` | board guessed from the domain, verified by the API |
| `jobs.lever.co/<company>/<uuid>` (and `.eu.`) | `LeverFetcher` | `api.lever.co/v0/postings/<company>/<uuid>`; Lever's "lists" become section headings |
| `jobs.ashbyhq.com/<org>/<uuid>` | `AshbyFetcher` | `api.ashbyhq.com/posting-api/job-board/<org>`, job found by id; closed jobs get a clear message |
| anything else | `GenericFetcher` | schema.org **JSON-LD `JobPosting`** first (many JS career sites — Workday, SmartRecruiters, iCIMS — embed it), visible page text second |

Router (`app/fetching/router.py`): first board fetcher whose `handles()` matches; if its API call fails (wrong guessed board, API down), fall back to the page itself. No keys, no paid APIs, no browser.

If a page is JavaScript-only with no JSON-LD, the generic fetcher refuses (less than 400 characters of text) and says to paste, instead of matching against navigation links.

## Files

| File | Function |
|---|---|
| `app/fetching/base.py` | `JobFetcher` (injectable `httpx.Client`), `FetchError`, `html_to_text` (keeps list items as `- ` lines, un-escapes Greenhouse's HTML) |
| `app/fetching/greenhouse.py`, `lever.py`, `ashby.py` | board APIs |
| `app/fetching/generic.py` | JSON-LD + page text + thin-page refusal |

## Also fixed while testing on live postings

- Benefits headings with a long label ("Benefits available to all full-time Ramp employees (Global)") are now recognised and skipped, instead of their perks landing in nice-to-have.
- Small security vocabulary added to the lexicon (IAM, threat modeling, SIEM, SOC 2, OWASP…).

## Tests

- `tests/unit/test_fetching.py` — offline via `httpx.MockTransport`: routing, HTML → text, each board, `gh_jid` guessing, JSON-LD `@graph`, thin-page refusal, board-API → page fallback.
- `tests/integration/test_boards_live.py` — `pytest -m network` (excluded by default): takes a currently open job from Stripe (Greenhouse), Palantir (Lever), Ramp (Ashby) so it doesn't rot when one posting closes.

## Not done

- Workday's own JSON API isn't used; its pages usually carry JSON-LD.
